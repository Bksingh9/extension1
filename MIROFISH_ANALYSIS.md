## 1. Project Overview

### What is MiroFish?

MiroFish is an AI-powered multi-agent prediction engine that creates **high-fidelity digital simulations** to forecast future outcomes. Think of it as a "digital sandbox" where thousands of intelligent AI agents simulate real-world social interactions, market dynamics, and public behavior.

### How It Works

```
Seed Material (news, data, novels)
        |
        v
  Natural Language Query ("What happens if X?")
        |
        v
  GraphRAG Knowledge Extraction
        |
        v
  OASIS Multi-Agent Framework (thousands of agents)
        |
        v
  Parallel Simulations with Temporal Memory
        |
        v
  Automated Reports + Interactive Agent Chat
```

### Tech Stack

| Component | Technology |
|---|---|
| Frontend | Vue.js (41.2% of codebase) |
| Backend | Python 3.11-3.12 (57.6%) |
| LLM APIs | OpenAI SDK-compatible (recommends Alibaba Qwen-plus) |
| Memory System | Zep Cloud (agent memory persistence) |
| Knowledge Base | GraphRAG construction from seed materials |
| Agent Framework | OASIS (from CAMEL-AI) |
| Runtime | Node.js 18+ |

### Key Features

- **Auto Digital World Construction** -- feed it news articles or datasets, it builds a simulated world
- **Multi-Agent Parallel Simulations** -- thousands of agents interact simultaneously
- **GraphRAG Knowledge Extraction** -- builds knowledge graphs from any seed data
- **Interactive Post-Simulation** -- chat directly with simulated agents after runs
- **Automated Report Generation** -- specialized ReportAgents create summaries
- **Natural Language Input** -- no coding needed for queries

## 3. Real-Life Use Cases

### Policy Analysis & Government
Simulate the impact of proposed regulations before implementation.
- *Example*: Model how a minimum wage increase affects employment, business closures, and consumer spending in a specific city.

### Financial Forecasting & Market Analysis
Simulate market reactions to major events.
- *Example*: Model how a tariff announcement propagates through supply chains and affects stock prices across sectors.

### Corporate Strategy & Scenario Planning
Test business decisions in simulated environments before committing resources.
- *Example*: Simulate a product launch in 3 different markets simultaneously to find the optimal go-to-market strategy.

### Public Opinion & PR Crisis Simulation
Model how public sentiment shifts in response to announcements.
- *Example*: Before a CEO makes a controversial statement, simulate how Twitter/X, news media, and consumer behavior react over 30 days.

### Insurance & Risk Assessment
Model catastrophic scenarios and their cascading effects.
- *Example*: Simulate how a natural disaster affects infrastructure, insurance claims, population movement, and recovery timelines.

### Urban Planning & Infrastructure
Simulate population movement and resource utilization under different development scenarios.
- *Example*: Model traffic patterns and housing demand if a new tech campus is built in a suburban area.

### Literary & Narrative Analysis
Explore alternate story outcomes and character behavior.
- *Example*: Publishers and screenwriters can test narrative directions before committing to production.

## 7. Risks & Honest Caveats

### Technical Risks
- **Early-stage software (v0.1.x)** -- expect breaking changes, bugs, and missing documentation
- **API dependency** -- if Qwen/OpenAI changes pricing or availability, your costs change
- **High compute costs** -- complex simulations can rack up API bills quickly
- **Keep simulations under 40 rounds initially** -- the project warns about resource consumption

### Business Risks
- **No published accuracy metrics** -- simulations are illustrative, not guaranteed predictions. Never market them as certainties
- **AGPL-3.0 license** -- if you deploy a modified version as a service, you MUST release your modifications as open source. Workaround: add value through your service layer, not code changes. Or negotiate a commercial license with Shanda
- **Growing competition** -- with 48.5k stars, others will build similar services. Move fast to establish your position
- **Regulatory concerns** -- "prediction" services may face scrutiny in financial or medical contexts. Include appropriate disclaimers

### What NOT to Do
- Do NOT promise guaranteed predictions to clients
- Do NOT use it for financial advice without proper disclaimers
- Do NOT ignore the AGPL license requirements
- Do NOT start with expensive, complex simulations -- build up gradually
