## How to Deliver a Consulting Engagement

### Step 1: Discovery Call (30 min)
- Understand the client's decision/scenario
- Identify key variables and stakeholders
- Define success criteria
- Agree on scope and timeline

### Step 2: Scenario Design (1-2 hours)
- Translate business scenario into MiroFish simulation parameters
- Select appropriate seed materials (industry data, news, market reports)
- Configure agent types (consumers, competitors, regulators, media)
- Define simulation rounds and variables

### Step 3: Run Simulations (2-8 hours)
- Run multiple simulations with varying parameters
- Document agent behaviors and emerging patterns
- Capture key data points and turning points
- Run sensitivity analysis (change one variable at a time)

### Step 4: Analysis & Report (4-8 hours)
- Analyze simulation results across all runs
- Identify consistent patterns vs outliers
- Create visualizations and charts
- Write executive summary and detailed findings
- Draft actionable recommendations

### Step 5: Presentation (1 hour)
- Walk client through findings
- Show key simulation moments
- Discuss implications and next steps
- Answer questions and refine recommendations
