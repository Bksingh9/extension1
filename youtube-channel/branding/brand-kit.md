## Visual Identity

### Color Palette
| Role | Hex | Usage |
|---|---|---|
| Background | #0a0a0f | Thumbnails, video bg |
| Card/Panel | #12121a | UI elements, overlays |
| Primary Blue | #3b82f6 | Headlines, accents, CTAs |
| Secondary Purple | #6366f1 | Secondary highlights |
| Success Green | #22c55e | Checkmarks, completion states |
| Warning Amber | #f59e0b | Alerts, problem scenes |
| Text Primary | #f1f5f9 | Headlines, body text |
| Text Secondary | #94a3b8 | Subtitles, labels |

### Typography
- **Headlines**: Inter, 700-800 weight, tight letter-spacing (-0.03em)
- **Code/Terminal**: SF Mono / Fira Code, 400 weight
- **Body**: Inter, 400 weight

### Thumbnail Style
- Dark background with blue/purple glow
- Bold white text (3-5 words max)
- Terminal or code UI elements
- Consistent bottom-right channel badge
- 1280x720 resolution

### Consistent Elements
- Every video starts with 5s branded intro
- Every video ends with 8s outro (subscribe CTA + next video)
- Lower-third for tool names uses blue accent bar
- Terminal panels use the same 3-dot window chrome

## Profile Picture Concept
- Dark circle background (#0a0a0f)
- Stylized "AR" monogram in electric blue (#3b82f6)
- Subtle glow effect behind letters
- Clean, minimal, recognizable at small sizes

## Brand Voice
- **Confident** but not arrogant
- **Technical** but accessible
- **Practical** -- always show real output
- **Premium** -- no cheap effects or clickbait styling
- Never use "INSANE" "CRAZY" "MIND-BLOWING" in titles
- Preferred power words: Build, Render, Create, Ship, Launch, Automate
