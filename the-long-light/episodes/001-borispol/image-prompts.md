# Episode 001 — Image generation prompts

> 40 numbered prompts mapped to the 7 scenes of `script.md`. Targets
> ~13.5s of screen time per image at the 9-minute runtime.
>
> All prompts use the same **style anchor** below. Paste the anchor at
> the top of every Imagen / Flux / Midjourney session for consistency,
> or append it to each prompt individually if your tool doesn't support
> session-level priors.

## Style anchor (use with every prompt)

> **Cinematic documentary still, 16:9 widescreen.** Deep navy-black background, almost black (`#0a0e1a`). Warm amber-gold light enters from one edge of the frame and falls off into the dark. Visible film grain, faint vintage-paper texture, archival photograph aesthetic. **No human faces in close-up** — silhouettes, hands, objects, and places only. **Lighting reference:** Christopher Nolan low-key palette, single-source warm key light, deep shadows. **Color palette:** dark navy, warm cream (`#f5e8d3`), signal yellow (`#ffb627`), burnt orange (`#d96e3b`), slate blue (`#4a6e85`). **Mood:** patient, melancholic, observational. **Format flags:** `--ar 16:9 --style raw --quality 2`.

## Production notes

- Every prompt above ends with the **Style anchor** placeholder. Either set the anchor as a session-level prior in your tool of choice, or paste it after each prompt individually. Imagen and Flux respect repeated style descriptors well; Midjourney users may want to add `--sref <reference-image>` once a hero frame is generated.
- **Consistency anchor.** The style anchor's *light from one edge into deep navy* is the single most important visual rule. If a generated image is too symmetrically lit, regenerate with stronger weight on `light from one edge`.
- **No faces.** If a prompt accidentally returns a recognizable face, regenerate with `silhouette only` added.
- **Negative prompts** (Midjourney `--no` / Flux negative): `--no faces, smiles, modern logos, plastic textures, neon, lens flares, anime, cartoon`.
- **Resolution target.** Generate at 2048×1152 minimum, upscale to 3840×2160 before edit. The Long Light is final-rendered at 4K like The Dossier.
- **Recommended generator order:** Imagen 3 (best for archival/photographic) > Flux Pro (best for cinematic) > Midjourney v6 (best for "single-light-source mood"). Pick one and stay with it for the whole episode — switching mid-episode breaks visual consistency.

## What to do with these images

1. Generate each numbered prompt one at a time; review against the script beat.
2. Save outputs to `the-long-light/episodes/001-borispol/visuals/{01..40}-<short-slug>.png` (4K).
3. The video edit step (Phase 7) drops these into the timeline in order, sized to 13.5s average each, with the cuts driven by VO pacing notes from `voice-notes.md`.
4. Anything that doesn't pass the *single-light-source mood* test — regenerate or skip.
